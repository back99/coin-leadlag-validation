# Coinbot: 코인 단타 전략 검증

"비트코인이나 이더리움이 오르면 알트코인이 뒤따라 오른다"는 단타 가설을,
실거래 인프라를 짓기 전에 데이터로 검증한 프로젝트입니다.

**결론: 전략 9가지를 모두 기각했습니다.** 알트코인은 비트코인을 시차 없이 거의 같은 순간에 따라가서,
신호의 가치(약 +0.1%)가 왕복 비용(0.115~1.022%)을 넘지 못했습니다.

자세한 결과와 근거는 [RESULTS.md](RESULTS.md)에 있습니다.

## 핵심 숫자

| 항목 | 값 |
|---|---|
| 데이터 | 업비트 5분봉 90일 (25,935바), 바이낸스 1초봉 2일 (종목당 약 17만 바), 업비트/빗썸 호가 |
| 지연 상관 | 1초 뒤 0.08, 1분 뒤 0.01 수준 |
| 신호 가치 vs 비용 | 약 +0.1% vs 왕복 0.115~1.022% (코인별 실측 스프레드 + 수수료) |
| 과최적화 확인 | 추세추종 인샘플 최적 +27.7% → 아웃샘플 -31.0% |
| 실거래 | 없음 (검증 단계에서 중단) |

## 검증 방법

- **대조군**: 무작위 진입, buy & hold, 랜덤워크 기준선과 항상 비교
- **아웃샘플**: 인샘플에서 고른 조건을 다른 기간에서 다시 검증
- **코인별 비용**: 실측 스프레드와 수수료를 코인마다 따로 적용
- **도구 검증**: 합성 데이터에 지연을 일부러 심어서 도구가 찾아내는지, 순수 노이즈에서 가짜 전략을 걸러내는지 먼저 확인 (`test_*.py`)

## 실행

```bash
pip install pandas numpy
python3 test_upbit_logic.py      # 로직 검증 (네트워크 없이 합성 데이터)
bash run_all.sh                  # 주요 검증 일괄 실행, 로그는 results/ 에 저장
```

- 데이터는 업비트, 바이낸스, 빗썸의 **공개 REST API**로 받습니다 (API 키 불필요).
- 받은 캔들은 `data/`, `data_upbit/`, `data_binance/`에 캐시됩니다 (저장소에는 포함하지 않음).
- 바이낸스 글로벌 API는 미국 등 일부 지역에서 접속이 제한될 수 있습니다.

## 주요 파일

| 파일 | 용도 |
|---|---|
| `leadlag_check.py` | 바이낸스 지연 상관 + 이벤트 스터디 |
| `upbit_leadlag_check.py` | 업비트 지연 상관 + 세션 + 비용 민감도 |
| `upbit_triggers.py` | 진입 트리거 비교 (무작위 대조군 포함) |
| `overnight_session_check.py` | 밤사이 → 한국 낮 세션 따라잡기 |
| `kimchi_premium_check.py` | 김치 프리미엄 신호 (랜덤워크 기준선 포함) |
| `intraday_season_check.py` | 시간대 계절성 (인샘플/아웃샘플) |
| `spread_collector.py`, `spread_analyze.py` | 호가 수집, 스프레드 vs 수수료, 거래소 간 차익 |
| `exit_backtest.py` | 청산 로직 백테스트 (익절/손절/탈출/포기) |
| `trend_follow_test.py`, `trend_oos_test.py` | 추세추종 vs buy & hold, 아웃샘플 검증 |
| `test_*.py` | 각 도구의 로직 검증 (합성 데이터) |
| `docs/` | 설계 단계 아키텍처 그림 (구현하지 않음) |

## 작업 방식과 AI 사용

이 프로젝트는 AI(Claude)와 함께 진행했습니다. **코드는 AI가 썼고, 저는 가설, 작업 순서, 실행, 검증, 판단을 맡았습니다.**

- **작업 순서**: AI가 코드와 폴더부터 만들려 할 때 멈추고 구조부터 정했고, AI가 낸 10단계 계획 중 "신호가 실제로 있는지 검증"부터 골랐습니다. LLM은 매매 결정에서 빼기로 했습니다.
- **사이클**: 제가 아이디어를 말하면 AI가 스크립트로 옮기고, 거래소 API가 제 컴퓨터에서만 접속돼서 수집과 검증 실행은 제가 맡았습니다 (9회). AI는 모아둔 데이터로 변형을 직접 돌렸습니다 (약 14회).
- **속도**: 이틀 동안 전략 9가지와 변형 약 20개. 새 가설은 20~40분, 변형은 5~15분 안에 결론을 냈습니다.
- **AI 결론을 반박해서 바뀐 것**
  - 고정 보유시간 청산만 쓰던 테스트를 지적해 청산 엔진 4가지(익절, 손절, 탈출, 포기)를 만들게 했고, 고정 청산이 이익 거래를 손실로 기록하던 결함을 확인했습니다 (+1.10% 거래가 -0.20%로 기록).
  - 알트코인이 비트코인을 1:1로 따라간다는 가정을 지적해 쌍별 베타를 재게 했고, 가짜 신호가 사라졌습니다 (보정 후 신호 30건 미만).
  - AI가 재지 않았던 순수 추세추종을 요청해 측정했고, 그냥 들고 있기보다 나빴습니다 (-5.2% vs -2.5%).
  - 김치 프리미엄 재검증, 선물 펀딩비 전략, 장기 호가 수집 제안은 거절했습니다.
